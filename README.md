# GestionStock

Application de gestion de stock avec un backend Node.js/Express et un frontend React Material Dashboard.

## Fonctionnalités

- Authentification utilisateur
- Gestion des utilisateurs
- Interface d’administration moderne
- Architecture séparée backend/frontend

## Technologies utilisées

- React
- Material Dashboard React
- Node.js
- Express
- MongoDB

## Structure du projet

- backend/: API et logique serveur
- material-dashboard-react/: interface utilisateur React

## Installation

### Backend

```bash
cd backend
npm install
node server.js
```

### Frontend

```bash
cd material-dashboard-react
npm install
npm start
```

## Déploiement

Le projet peut être publié sur GitHub Pages, Netlify, Vercel ou un serveur Node.js.
